Premier League Match Predictor

Extract the whole ZIP to one folder. From that folder, run

    python -m pip install -r requirements-notebook.txt

Copy your local premier_league.csv and fixtures_2026_27.csv into the extracted
folder, or download the results directly from the provider with

    python -m predictor refresh

Open Premier_League_Predictor.ipynb in Jupyter or your IDE, select Python 3,
and choose Run All. Set LIVE_SEASON = True in the season cell to load the
official fixtures online if you are using a fresh results download.

README.md has the methods, results, API, Docker, and scoreboard instructions.
Project_Comparison.md summarizes how the previous model and new project compare.
